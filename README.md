MAIN NOTE: PLEASE DOWNLOAD FROM RELEASES

These are build tools for fnf, with their specific versions included,
first use universal folder's content to install what's needed for all build tools,
then run the "install.bat" file to pick whatever versions of fnf you want to compile,
including most mods that use them.
If you want to compile a specific mod that wont use base engine tools correctly,
try installing the mod specific tools instead if available.

INSTALLATION NOTE: If haxelib refuses to install tools or libraries,
run haxelib setup and choose your HaxeToolkit lib folder,
press enter if you want to use default path.
This only happens on certain instances of fresh Haxe installs,
because the library folder isn’t created yet.
If it still errors out because the folder doesn’t exist,
create it manually before running setup.
